# Made With Free Software WaterMark

为你的由自由软件构建的作品提供 “Made With Free Software” 水印。

## 目录结构

```text
.
├── en/
│   ├── svg/
│   └── png/
└── zh-CN/
    ├── svg/
    └── png/
```

每个语言文件夹下各有 `svg/` 和 `png/` 两个子目录。
语言文件夹名使用 BCP 47 标签（如 `en`、`zh-CN`），后续新增语言按同一结构添加即可。

## SVG 版本说明

命名规则：`-B` = 黑底浅字，`-W` = 白底深字；后缀 `-outlined` 表示文字已转路径，`-changedAlpha` 表示调整过整体透明度。

| 文件名 | 水印底色 | 文字 | 适用场景 |
| --- | --- | --- | --- |
| `-B.svg` | 黑底 | 可编辑 `<text>` | 需要改字、文件轻量 |
| `-W.svg` | 白底 | 可编辑 `<text>` | 需要改字、文件轻量 |
| `-B-outlined.svg` | 黑底 | 已转路径 | 最终使用、跨设备一致 |
| `-W-outlined.svg` | 白底 | 已转路径 | 最终使用、跨设备一致 |
| `-B-outlined-changedAlpha.svg` | 黑底 | 已转路径、调整透明度 | 最终使用、跨设备一致，开箱即用 |
| `-W-outlined-changedAlpha.svg` | 白底 | 已转路径、调整透明度 | 最终使用、跨设备一致，开箱即用 |

> 黑底浅字（`-B`）适合贴在浅色作品上；白底深字（`-W`）适合贴在深色作品上。

## PNG 版本说明

为方便部分用户，`png/` 下按黑白、透明度不同各导出一份 `.png`，可直接拖入作品使用。

## 许可证

- 水印本身：**CC0 1.0**（可自由使用、修改、商用，无需署名）

## 为什么说这是一种微小的“黑客行为”？

> 使用本水印本身，就是一种微小的“黑客行为”。

在默认情况下，各大平台和商业软件往往在无形中推动你接受“专有”生态。而当你选择使用本水印，并将它打在自己创作的作品上时，你实际上完成了一次微小的“Hack”：

- 你绕过了默认的版权叙事，向观众宣告了“自由软件”的存在；
- 你使用的是纯文本、可审阅的 SVG，而不是被大厂锁死的专有格式；
- 本水印使用CC0协议，所以在你的作品里使用它也是一次黑客行为。
