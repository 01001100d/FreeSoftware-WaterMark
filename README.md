# Made With Free Software WaterMark

为你的由自由软件构建的作品提供“Made With Free Software”水印。

| 版本 | 背景 | 文字 | 适用场景 |
| --- | --- | --- | --- |
| `-B.svg` | 浅色 | 可编辑 `<text>` | 需要改字、文件轻量 |
| `-W.svg` | 深色 | 可编辑 `<text>` | 需要改字、文件轻量 |
| `-B-outlined.svg` | 浅色 | 已转路径 | 最终使用、跨设备一致 |
| `-W-outlined.svg` | 深色 | 已转路径 | 最终使用、跨设备一致 |
